Version 2: RestFuzzBench

Usage of files:

Targeted services files:
/services/wordpress/ --> wordpress related setup
/services/woocommerce/ --> woocommerce related setup


Setup related files:

/scripts/execution/build_all.sh --> This file build all the integrated fuzzers (WIP)
/scripts/execution/exec_all.sh --> This file execute all the integrated fuzzers in a system (WIP)
/scripts/execution/exec_common.sh --> This file selects different fuzzers and update configuration require for them and invoke the docker container for the targeted fuzzer


Experiment related files:

/scripts/merge_csv.sh --> This file takes argument to run different kind of fuzzers and generates the csv output of code coverage that can be used for analysis
/scripts/analysis.py --> This file reads the output generated by fuzzer and create a graph to analyse the code coverage of fuzzer
